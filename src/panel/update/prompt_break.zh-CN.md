# 破限方案

选择变量更新模型使用的提示词。此设置和相关选项会随 API 方案保存。

## 使用内置破限

使用 MVU 内置的变量更新提示词。感谢 @离 提供破限提示词，主要面向 Gemini 和 Claude，也可用于其他模型。

## 使用当前预设

使用酒馆当前预设中的提示词。如果预设要求续写剧情，变量更新模型也可能继续写故事，导致变量更新对应的是后续剧情，而非当前回复。

## 使用其他预设

从列表中选择一个已保存的预设，使用其中的提示词，不会切换酒馆当前正在使用的预设。

- 请先保存预设修改；这里不会读取尚未保存的内容。
- 正则处理仍沿用酒馆当前的设置。
- 模型、API 地址等仍使用“模型来源”中的配置。
- 只使用所选预设的提示词，不运行其中的额外脚本，也不应用其 API 设置。
