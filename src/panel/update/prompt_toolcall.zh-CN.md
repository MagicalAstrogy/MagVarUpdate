# 应答格式

决定模型怎样返回变量更新结果。此设置会随 API 方案保存。

- **聊天消息**：兼容性最好。不确定服务商支持哪些功能时，可以先选这个；更新是否成功取决于模型能否按提示词要求回复。
- **工具调用**：需要模型和服务商支持“工具调用”（也称 function
  calling），通常能减少无关正文对变量更新的干扰。
- **格式化输出**：需要服务商支持 JSON Schema，可以约束模型返回的格式，让变量更新更稳定。
- **格式化输出（v4 兼容）**：适合只支持 JSON Object、不支持 JSON
  Schema 的渠道，例如 dsv4f。可用于“自定义”和“更多”中支持该功能的来源。

如果服务商明确支持 JSON Schema，可以尝试“格式化输出”；只支持 JSON
Object 时，选择“格式化输出（v4 兼容）”。支持工具调用时，也可以尝试“工具调用”。

模型列表中的功能提示仅供参考。如果请求提示不支持当前格式，请换一种应答格式，或检查来源、API 地址和模型名称。MVU 不会自动改用其他格式。
